AWS Glue Connector Python Package

Writes Tabsdata tables as Apache Iceberg tables on Amazon S3, registered in the
AWS Glue Data Catalog. The tables can then be queried with Amazon Athena and any
other engine that reads the Glue Data Catalog.

Warning: this is not a standalone package. It is an `extra` of the Tabsdata package.
Refer to the Tabsdata package for details on how to install it: https://pypi.org/project/tabsdata/
