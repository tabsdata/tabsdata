# Getting Help

- To learn how Tabsdata works and how to build it, read the [README](README.md) and
  [Developing Tabsdata](DEVELOPING.md).
- To report a bug or to suggest an improvement, search the
  [existing issues](https://github.com/tabsdata/tabsdata/issues) first, then open a new one if
  nothing matches.
- To report a security vulnerability, follow the [Security Policy](SECURITY.md).
- For the product documentation, see the [Tabsdata docs](https://docs.tabsdata.com).
